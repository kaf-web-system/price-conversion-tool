# Amazon価格改定ツール（プロトタイプ）

徳山様（オーディオケーブル販売）のAmazon出品約14,000件を、キーワード＋単価設定で一括価格改定するためのローカルWebツールです。

## できること

1. Amazon出品レポートCSV（Seller Central出力、CP932/Shift-JISでもOK）を読み込む
2. 「商品名にこのキーワードが含まれる商品は、1m単価×長さ＋プラグ単価×個数を加算する」というルールを画面上で複数設定
3. 商品名から自動で「長さ(m)」「本数(本/ペア/ch)」を抽出して新価格を計算
4. **自動改定できた商品** と **手動対応が必要な商品** に分けて結果表示
5. それぞれをCSVでダウンロード（Amazonインポート用 / 手動レビュー用）

## ローカル起動手順

ターミナルで以下を実行してください。

```bash
cd /Users/chanchan/apps/amazon-price-tool
npm install         # 初回のみ
npm run dev
```

起動後、ブラウザで <http://localhost:3000> を開く。

## 使い方

1. **CSVを選ぶ** — Amazonの出品レポートCSVを選択（「Activeのみ対象にする」推奨）
2. **キーワードと加算額を設定** — 表示名 / 正規表現パターン / 1m単価 / プラグ単価 を型番ごとに入力
3. **価格改定を実行** をクリック
4. **結果** で件数とプレビューを確認 → 2種類のCSVをダウンロード

## 出力CSV

### `amazon_price_update.csv`（自動改定用）
```
sku,price
00-43XJ-N40H,35900
```
→ Amazonセラーセントラルの「在庫」→「アップロードによる一括設定」に流し込む想定。実際のインポート用列名は徳山様/Amazonの仕様に合わせて要調整。

### `manual_review_list.csv`（手動対応用）
```
sku,asin,商品名,現在価格,手動対応理由
```
→ Excelで開いて目視で価格を決め、手動でAmazonに反映。

## 計算ロジック

```
新価格 = 現在価格 + (長さm × 1m単価) + (個数 × プラグ単価)
```

- 長さ: 商品名の `(4m)` `(25cm)` `(1.5m)` から抽出
- 個数: `2本ペア` `4本セット` `8ch` `ペア` から抽出（無ければ1）
- どれにも当てはまらない商品は手動対応リストへ

## 注意

- 正規表現＋手動入力した型番マスタで動作。Claude API連携は次フェーズ。
- 出力CSVを生成しただけでは反映されません。徳山様がAmazonにアップロードして初めて価格が変わります。
- 必ずサンプルで「変更前→変更後」を目視確認してください。
